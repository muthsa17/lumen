# LUMEN MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun web app LUMEN yang bisa didemokan. Isinya: Landing, login (email/tamu), Micro-Task Breakdown, Energy Check-in, dan Adaptive Focus Timer. Aplikasi di-deploy ke Vercel.

**Architecture:** SPA React + Vite tanpa backend sendiri. Data dan auth ditangani Supabase dengan RLS per user. Aturan bisnis ditulis sebagai fungsi murni di `src/lib/` yang dites dengan Vitest. Hook di `src/hooks/` membungkus `supabase-js` dan localStorage. Halaman di `src/pages/` dan komponen fitur di `src/features/` hanya merakit hook dan komponen shadcn.

**Tech Stack:** Node 24, Vite 8 (`react-ts`), React 19.2.7+, TypeScript, Tailwind v4, shadcn/ui, lucide-react, React Router v8, `@supabase/supabase-js`, Vitest, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-13-lumen-tech-stack-design.md`. Baca spec dan plan ini bersamaan. Plan ini merujuk ke nomor bagian spec, misalnya "spec §4.3".

## Global Constraints

Aturan ini berlaku di semua task:

- Gunakan Node ≥ 22.22 (target: Node 24 LTS) dan React ≥ 19.2.7.
- Import router dari `react-router`, dengan `RouterProvider` dari `react-router/dom`. **Jangan** memakai `react-router-dom`.
- Pakai komponen `sonner` untuk notifikasi toast. **Jangan** memakai komponen `toast` shadcn.
- **Jangan** membuat `tailwind.config.js`. Semua token ditulis di `src/index.css` (spec §7.4).
- Env yang dipakai hanya `VITE_SUPABASE_URL` dan `VITE_SUPABASE_PUBLISHABLE_KEY`. **Jangan pernah** memakai service-role/secret key di frontend.
- RLS aktif di semua tabel dengan policy `(select auth.uid()) = user_id`.
- Semua teks UI dalam Bahasa Indonesia.
- Untuk tanggal "hari ini", **selalu** pakai tanggal lokal `YYYY-MM-DD` dari `todayLocal()` (Task 3). **Jangan** memakai `new Date().toISOString().slice(0,10)`, karena hasilnya UTC dan salah hari setelah jam 17.00 WIB.
- Ambil warna dari token (`bg-green`, `text-ink`, `bg-primary`, dll.). Hex mentah di komponen **dilarang**.
- Tombol utama: teks `--primary-foreground` (`#181818`) di atas `#05AF6C` (spec §7.5).
- Tidak ada fitur di luar spec §1–§6, termasuk dark mode, OAuth, CAPTCHA, statistik, dan i18n.
- Commit kecil per task. Format pesan Conventional Commits.

## Review Focus

Kondisi berikut tidak tercakup langsung oleh alur utama, tetapi paling mungkin merusak pengalaman pengguna. Tes untuk masing-masing sudah dimasukkan ke task pemiliknya.

1. **Pengguna membuka app di malam hari WIB (UTC+7).** Tugas "hari ini" dan check-in harus memakai tanggal lokal, bukan UTC. Dites di Task 3 lewat `todayLocal`.
2. **Isi localStorage timer rusak atau dari versi lama.** Contohnya JSON invalid, `phase` tidak dikenal, atau `endAt` bukan angka. App tidak boleh crash; timer kembali ke kondisi idle. Dites di Task 4 lewat `loadTimer`.
3. **Pengguna menutup tab lalu kembali setelah waktu fokus habis.** Sisa waktu harus 0 (tidak negatif), dan aksi selesai harus berjalan sekali. Dites di Task 4 (`remainingMs`) dan Task 9 (cek manual).
4. **Browser tanpa `Notification`** (Safari iOS non-PWA) **atau izin ditolak.** Timer tetap berjalan dan dialog jeda tetap muncul, hanya tanpa notifikasi sistem. Dites di Task 4 lewat `canNotify`.
5. **Tamu menekan "Keluar".** Data tamu tidak bisa dipulihkan setelah logout, jadi wajib ada konfirmasi berisi peringatan sebelum `signOut`. Dicek manual di Task 6.

### Task 9: Adaptive Focus Timer

**Files:**
- Create: `src/hooks/useTimer.ts`, `src/features/focus/BreakDialog.tsx`, `public/chime.mp3` (suara pendek berlisensi bebas, < 50 KB)
- Modify: `src/pages/Focus.tsx`

**Interfaces:**
- Consumes: `TimerState`, `TIMER_KEY`, `loadTimer`, `remainingMs`, `canNotify` (Task 4), `pickBreak` (Task 4), `useEnergyLevel` (Task 8), `ENERGY_RULES` (Task 3)
- Produces: `useTimer(onFinish: (phase: Phase) => void): { state: TimerState; remaining: number; start(phase: Phase, minutes: number): void; stop(): void }`

- [ ] **Step 1: Buat `useTimer`**
  - Inisialisasi dari `loadTimer(localStorage.getItem(TIMER_KEY))`, dibungkus `try/catch`.
  - `start` menulis `{ phase, endAt: Date.now() + minutes * 60_000 }` ke localStorage. `stop` menghapus key tersebut.
  - `setInterval` 1 detik dan listener `visibilitychange` sama-sama memanggil satu fungsi `tick()`.
  - Di dalam `tick()`, kalau `state && remainingMs(state, Date.now()) === 0`:
    1. Baca ulang `loadTimer(localStorage.getItem(TIMER_KEY))`.
    2. Kalau hasilnya `null`, berarti tab lain sudah menangani. Cukup set state lokal ke `null`, **tanpa** memanggil `onFinish`.
    3. Kalau masih ada, hapus key dan state lokal terlebih dahulu, baru panggil `onFinish(phase)`.

    Urutan ini membuat `onFinish` hanya berjalan sekali, termasuk saat `/focus` terbuka di dua tab (Review Focus #3).

- [ ] **Step 2: Buat halaman `Focus`**
  - Tampilkan durasi dari `ENERGY_RULES[useEnergyLevel()]`.
  - Countdown ditampilkan dalam format `mm:ss` dengan `font-heading text-h1`. Tampilkan juga `Progress`.
  - Tombol **Mulai fokus**:
    1. Jika `'Notification' in window && Notification.permission === 'default'`, panggil `Notification.requestPermission()`. Pemanggilan ini harus terjadi di dalam handler klik.
    2. Panggil `start('focus', focusMin)`.
  - Tombol **Berhenti** memanggil `stop()`.
  - Di bawah timer, tampilkan judul micro-task pertama dari "Fokus hari ini" sebagai konteks.

- [ ] **Step 3: Isi `onFinish`**

Urutan langkah ini penting. Notifikasi harus selalu paling akhir.

1. Untuk phase `focus`: buka `BreakDialog` dengan `pickBreak()` dan tombol "Mulai jeda", yang menjalankan `start('break', breakMin)`. Untuk phase `break`: tampilkan toast "Jeda selesai, siap fokus lagi?".
2. Putar `new Audio('/chime.mp3').play().catch(() => {})`.
3. Kalau `canNotify()`, jalankan `try { new Notification('Waktunya jeda', { body: tip.title }) } catch {}`. Di Chrome Android, constructor ini melempar `TypeError: Illegal constructor` walaupun izinnya `granted`. Karena itu notifikasi harus dibungkus `try` dan dipanggil paling akhir, supaya dialog jeda tetap terbuka.

- [ ] **Step 4: Verifikasi manual**

Untuk tes ini, ubah sementara `minutes` menjadi `0.1` (6 detik). **Kembalikan nilainya sebelum commit.**

|---|---|

| Refresh di tengah countdown | Countdown berlanjut dengan sisa waktu yang benar |
| Tolak izin notifikasi | Dialog jeda tetap muncul |
| Buka `/focus` di dua tab, tunggu waktu habis | Suara hanya **sekali** |
| Isi `localStorage['lumen.timer']` dengan `"x"`, lalu refresh | Timer idle, tidak crash |
